# مصروفاتي – تطبيق ويب للآيفون
## التشغيل
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. من Settings > Pages اختر Deploy from a branch ثم main و /root.
3. افتح رابط GitHub Pages على الآيفون باستخدام Safari.
4. اضغط مشاركة ثم Add to Home Screen ثم Add.
## الخصوصية والبيانات
المصروفات والميزانية تحفظ في localStorage على الجهاز/المتصفح فقط ولا تُرسل لخادم. استخدم الإعدادات > تصدير بانتظام للاحتفاظ بنسخة احتياطية. مسح بيانات Safari قد يحذف البيانات المحلية.
ملاحظة: التثبيت والعمل دون اتصال يتطلبان استضافة HTTPS. التطبيق لا يحتاج App Store ولا حساب مطور Apple.
